A digit reader made of logic gates

Draw a digit. There are no weights or multiplications here: every decision is made by AND, OR, XOR and friends, wired into a circuit that was learned by gradient descent and then frozen.

Train it soft

Each gate starts as a blend of all 16 two-input boolean functions, using a smooth version of each so the network can be trained with ordinary backpropagation.

Freeze it hard

After training, every gate keeps only its most likely function. What's left is a plain boolean circuit, which is then simplified: the trained gates shrink to the ones you're running now.

Count the votes

The final gates are split into ten equal groups, one per digit. The group with the most gates outputting 1 wins. That's the whole classifier.
